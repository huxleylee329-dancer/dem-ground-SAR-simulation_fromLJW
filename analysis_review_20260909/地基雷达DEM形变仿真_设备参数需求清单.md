# 地基雷达 DEM 与形变图像仿真：设备参数需求清单

用途：根据已有山体 DEM 和设定的形变场，模拟地基雷达复图像、两期干涉相位及视线向位移，用于研究地形映射、形变相位和后续处理。不开展原始回波与发射波形仿真。

请提供拟使用的具体型号、工作模式及该模式下的一套实际配置。若参数随模式或监测距离变化，请注明适用条件；没有的数据可标注“暂无”。请区分设备能力上限与本次实际配置。

## 可直接发送给设备方的请求

您好，我们计划基于山体 DEM 开展地基雷达图像级形变仿真，生成形变前后的复图像与干涉相位，不涉及原始回波仿真。为使几何、图像分辨率、采样网格及形变测量性能与设备一致，希望提供以下参数或对应说明书。优先提供第 1–10 项；现场安装尚未确定的参数，可提供推荐布设条件或安装示意图。

| 编号 | 参数项目 | 希望提供的具体内容 | 单位/格式 |
|---|---|---|---|
| 1 | 设备型号与成像方式 | 型号、拟采用工作模式；直线导轨 SAR、圆弧 SAR、实孔径旋转扫描、阵列扫描或其他方式；形变结果采用哪一收发通道 | 文字说明、系统示意图 |
| 2 | 载频与收发构型 | 实际中心频率或波长；Tx/Rx 数量和相对布局；收发是否可按同置处理；若分置，提供相位中心间距及方向 | GHz/Hz、m、布局图 |
| 3 | 雷达位置与安装姿态 | 雷达参考点/有效相位中心的位置，参考点到相位中心的偏移，天线离地高度；指向方位角、俯仰角，必要时横滚角；说明角度零点、正方向及坐标/高程基准 | XYZ/ENU 或经纬高；m、° |
| 4 | 扫描覆盖与有效监测范围 | 实际使用的最小/最大斜距；水平方位扫描起止角；俯仰覆盖或垂直波束宽度；推荐有效监测距离 | m、° |
| 5 | 输出图像坐标及像素间隔 | 图像是距离–方位角、距离–横向坐标还是地理编码网格；距离向像素间隔、方位向角度/长度间隔；首像素距离、起始角、行列数、轴向顺序和无效像素定义 | m/pixel、°/pixel 或 mrad/pixel；参数文件 |
| 6 | 实际空间分辨率 | 当前模式下的距离向分辨率、方位/横向分辨率；若横向分辨率随距离变化，提供角分辨率或距离–分辨率关系；注明分辨率定义及处理/加窗条件 | m、°、mrad 或对应表格 |
| 7 | 扫描几何简图 | 直线导轨：有效扫描长度、方向；圆弧扫描：半径、旋转中心、有效角范围；实孔径旋转：旋转轴、天线相位中心相对轴的偏移；其他构型提供等效几何说明 | m、°、图纸；逐采样点轨迹非本阶段必需 |
| 8 | 时间采样 | 一幅图像的完整扫描时长、相邻两幅图像的重访/输出间隔、时间戳定义；是否多次扫描平均及其时间窗 | s/min、时间说明 |
| 9 | 形变测量性能与稳定性 | 视线向位移重复精度或稳定目标位移标准差，或相位标准差；对应距离、目标类型、SNR/相干条件、平均次数；是否经过大气校正 | mm、rad、测试条件 |
| 10 | 相位和位移产品定义 | 位移正值表示靠近还是远离雷达；相位差采用的先后时相顺序；参考时刻、参考点/参考区；是否滤波、多视、解缠、大气校正；能否输出复图像或幅度与相位 | 说明、数据格式文档 |

以下资料若已有，建议一并提供：

| 优先级 | 资料 | 目的 |
|---|---|---|
| 建议 | 同一稳定场景的两期或多期复图像（或幅度+相位），附成像参数、时间戳、站位、处理状态与有效掩膜；相干图若有也请提供 | 校验图像网格、真实相位噪声、残余条纹、系统漂移；少量裁剪数据即可，无需原始回波 |
| 建议 | 点目标/角反射器的二维响应或距离向、方位向响应曲线；否则提供主瓣宽度、旁瓣指标和加窗方式 | 建立当前程序所需的图像级成像核 |
| 建议 | 极化方式及天线水平/垂直方向图；只有波束宽度也可以 | 改进幅度与覆盖仿真，明确散射模型适用条件 |
| 可选 | 有效成像带宽 | 分辨率资料不足时辅助估计距离响应；已有实测分辨率与响应时不是刚需 |
| 可选 | 安装重复定位精度、通道/时钟漂移、系统残余相位校正说明；如涉及搬站，提供每期站位 | 研究设备移动或相位漂移引起的伪形变 |
| 可选 | 设备标称的无模糊位移增量/形变速率范围及其条件 | 设置与扫描间隔一致的形变试验；避免混淆理论相位周期与软件解缠后的工作范围 |

其中“图像像素间隔”和“实际空间分辨率”请分别提供。例如输出像素为 0.1 m，不代表设备能分开相距 0.1 m 的两个目标。若方位性能用 m 表示，请注明对应的观测距离。

## 我方/现场方另行准备的数据

这些数据不是雷达型号自带的设备参数，应由仿真方、测绘方或现场布设方准备。

| 数据 | 需要明确的内容 |
|---|---|
| 山体 DEM | 文件格式、行列数、水平网格间隔、坐标系、水平与高程单位、高程基准、无效值；实际场景还需 DEM 空间覆盖 |
| 现场雷达布设 | 在 DEM 同一坐标基准下的雷达位置与朝向；只有离地高度不够确定雷达到山体各点的距离 |
| 形变场 | 形变区域、方向、幅度、时间规律；优先定义各点三维位移 `(uE,uN,uU)`，也可直接定义 LOS 位移用于纯相位试验 |
| 稳定参考 | 不发生形变的参考区域、参考点或角反射器，以及第一期参考时刻 |
| 散射模型 | 地表类型、相对散射强度、随机散射场及其跨时相相关性；初期可采用理想模型，后续用实测图像标定 |
| 可选误差场 | 大气路径延迟、时间去相关、站位误差及噪声强度；先做理想场景时可置零或分组控制 |

山体滑移不应一律建模成“DEM 高度变化”。沿坡滑移通常同时包含水平和垂直分量；初期可假设两次扫描之间各散射点移动、单次扫描期间场景静止。若模拟快速运动，再利用扫描时长设置时变形变。

## 与当前程序的对应关系

| 当前代码/变量 | 地基形变仿真中的替代或调整 |
|---|---|
| `Wlength` | 用设备实际中心频率计算波长 |
| `C` | 根据实际收发路径确定相位系数；同址单站常用双程系数，不能按“地基”两个字自动选取 |
| `descending_left.csv`、`compute_center`、`computefd*` | 替换为地基安装几何及相应扫描/像素映射，不能继续依赖卫星零多普勒轨道索引 |
| `DEM`、`Ell2xyz` | 使用统一局部坐标或先把地理坐标转换到统一坐标；保留逐点三维几何 |
| `Drange`、`DAzimath` | 拆分为像素采样间隔与实际空间分辨率；方位可能是角度网格，不一定是固定米制网格 |
| `ImageRange`、`ImageAzimath` | 由距离门、扫描角和像素间隔确定，或直接采用设备输出网格 |
| `Wright`、`conv2` | 根据实际分辨率/点扩散响应建立图像核；横向响应随距离变化时采用相应模型 |
| `para_line`、`ver_line`、`fd0pos_slave` | 普通固定站重复观测时，改成同一设备对两期形变场景成像，不再人为布置双星空间基线 |
| `sigma`、`RandAngle` | 两期使用对应的散射点和相关的散射相位；初期可保持散射场相同，仅改变位置 |
| `awgn(...,10)` | 按设备或实测数据确定的图像噪声/相位稳定性重设；位移精度、相位噪声、SNR并非可无条件互换 |
| `interferometric_phase` | 保留两期复图像干涉逻辑，统一位移正负和时相顺序 |
| 去参考相位、控制点校正 | 使用零形变参考场景/稳定区和实际站位，区分设备与大气残差、真实形变 |

这里的两期“主辅图像”一般是时间上的参考期与监测期，而不是两个相距数百米的平台。合成孔径扫描轨迹不等于两期观测之间的空间基线。如果设备使用多个接收通道，或两期搬站，则额外使用实际通道/站位几何。

同址单站情况下，可设 `P2=P1+u`，计算两期精确距离。对于当前代码 `angle(SLC1*conj(SLC2))` 的顺序，无噪声单点有 `phi12=4*pi*(R2-R1)/lambda`（按主值缠绕）。取远离雷达为正，则小位移下 `R2-R1` 为 LOS 位移；若设备采用相反时相顺序或符号定义，应相应调整。

单站雷达测得的是视线向位移，而非不加约束的三维滑移矢量。三维形变可作为仿真输入，但其雷达观测量需投影到视线方向。设备商对这一观测量的说明见 [IDS GeoRadar](https://idsgeoradar.com/products/software/smart-data)。

## 本阶段无需优先索取

既然不模拟回波，ADC 原始采样率、脉冲宽度、调频斜率、原始快时间采样点数、逐脉冲数据，以及发射功率、接收增益、噪声系数均不是第一批必需参数。已有输出图像几何、实际空间分辨率和噪声统计时，不必用这些底层量反推。

PRF 也不是本次必须照搬的配置；更重要的是一幅图像的扫描时长和相邻图像间隔。当前程序将 PRF 用于卫星轨道索引，这部分应修改。如果设备方无法提供图像响应，只能提供孔径/天线参数，再补充相应参数来推导近似响应。

设备类型必须先确认：地基监测设备既有 SAR，也有实孔径旋转扫描，例如 [GAMMA GPRI 官方说明](https://www.gamma-rs.ch/instruments/gpri)明确其为实孔径系统。此处引用仅用于说明为何需要询问成像方式，不把该型号数值作为本次仿真默认值。
